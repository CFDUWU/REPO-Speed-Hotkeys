# Game Speed Hotkeys

Change the game speed with hotkeys.

| Key | Speed |
|-----|-------|
| F1 | 0.25x |
| F2 | 1x (normal) |
| F3 | 2x |
| F4 | 5x |
| F5 | 10x |
| F6 | 15x |
| F7 | 0.001x |

Pressing the key of the active speed again returns to normal (1x).
